# JOY Mobile — Shopify theme

ה-theme של החנות הארצית JOY Mobile בשופיפיי. בעברית ומימין לשמאל, להזמנות עם משלוח עד הבית. לחנות אילת יש תבנית מקבילה במאגר `YonatanKing12/joymobile`, עם תוכן ותנאים המתאימים לשריון ואיסוף באילת.

## מה יש כאן
- `layout`, `templates`, `sections`, `snippets`: ה-theme (Online Store 2.0, תבניות JSON וקבוצות מקטעים).
- `assets`: CSS לכל רכיב, מודולי JavaScript בלי ספריות חיצוניות (נטענים דרך import map), הגופן Assistant והלוגואים של JOY.
- `config`: ההגדרות וערכי ברירת המחדל שלהן. הצבעים: `#309d7a`, `#060433`, `#f0f3ff`, `#56d2aa`, `#e0fff2`.
- `locales/he.default.json`: כל הטקסטים באתר.

## חיבור לחנות
חנות אונליין ← ערכות נושא ← הוספת ערכת נושא ← חיבור מ-GitHub, ובוחרים את הריפו הזה ואת הענף `main`.
שופיפיי יוצרת theme חדש שמסונכרן עם הענף. כדאי לבדוק אותו בתצוגה המקדימה לפני שמפרסמים.
הבאנרים והתמונות של דף הבית נמצאים בספריית הקבצים של החנות, ולכן הם מוצגים רק בחנות של JOY Mobile.

## בדיקות

היסטוריית הפיתוח המלאה, כולל הבדיקות, נמצאת בריפו `YonatanKing12/joymobile`, בענף `claude/eloquent-sagan-oxark2`.

## תוכן וסדר מוצרים

- בעורך דף הבית, `מוצרים מוצמדים` בכל קרוסלה קובע את המוצרים המובילים ואת סדרם. מוצר שאזל מהמלאי אינו מוצג; שאר הקטלוג ממשיך להופיע לפי הקולקציות המוגדרות.
- בסקשן המדריכים, סדר בלוקי `מאמר מוביל` קובע אילו מאמרים מהבלוג המוגדר מופיעים ראשונים. בחירת קולקציה מספקת את הנושא והתמונה כאשר למאמר אין תמונה משלו. מאמרים אחרים ממשיכים להופיע אחריהם.
- כתובת סניף הדגל בתחתית וכתובת בכרטיס הקשר הן הגדרות מקומיות לסקשן. הן אינן משנות את זהות החנות הארצית או את מסלול המשלוח. נתוני סניף הדגל במטא־אובייקט ממשיכים לקבל עדיפות בתחתית.
- קיצור הדרך למעבדת JOY FIX מוביל לכרטיסי הסניפים בצור קשר כל עוד עמוד המעבדה אינו מפורסם. כשהעמוד מפורסם, הקיצור חוזר אליו אוטומטית.

עמודי אודות ומדיניות, תפריטים, תיאורי מוצרים ומטא־אובייקטים נשמרים ב־Shopify בנפרד מהתבנית. [כלי עדכון התוכן וההוראות](.github/storefront-remediation/README.md) כוללים את התיקונים המוכנים ואת בדיקות המצב לפני הפעלה.
