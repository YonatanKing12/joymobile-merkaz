# JOY Mobile — Shopify theme

ה-theme של החנות הארצית JOY Mobile בשופיפיי. בעברית ומימין לשמאל, להזמנות עם משלוח עד הבית. לחנות אילת יש תבנית מקבילה במאגר `YonatanKing12/joymobile`, עם תוכן ותנאים המתאימים לשריון ואיסוף באילת.

## מה יש כאן
- `layout`, `templates`, `sections`, `snippets`: ה-theme (Online Store 2.0, תבניות JSON וקבוצות מקטעים).
- `assets`: CSS לכל רכיב, מודולי JavaScript בלי ספריות חיצוניות (נטענים דרך import map), הגופן Assistant והלוגואים של JOY.
- `config`: ההגדרות וערכי ברירת המחדל שלהן. הצבעים: `#309d7a`, `#060433`, `#f0f3ff`, `#56d2aa`, `#e0fff2`.
- `locales/he.default.json`: כל הטקסטים באתר.

## חיבור לחנות
חנות אונליין ← ערכות נושא ← הוספת ערכת נושא ← חיבור מ-GitHub, ובוחרים את הריפו הזה ואת הענף `main`.
שופיפיי יוצרת theme חדש שמסונכרן עם הענף. כדאי לבדוק אותו בתצוגה המקדימה לפני שמפרסמים.
הבאנרים והתמונות של דף הבית נמצאים בספריית הקבצים של החנות, ולכן הם מוצגים רק בחנות של JOY Mobile.

## בדיקות
Theme Check: 0 שגיאות ו-0 אזהרות (`shopify theme check`).
היסטוריית הפיתוח המלאה, כולל הבדיקות, נמצאת בריפו `YonatanKing12/joymobile`, בענף `claude/eloquent-sagan-oxark2`.

## תוכן וסדר מוצרים

- בעורך דף הבית, `מוצרים מוצמדים` בכל קרוסלה קובע את המוצרים המובילים ואת סדרם. מוצר שאזל מהמלאי אינו מוצג; שאר הקטלוג ממשיך להופיע לפי הקולקציות המוגדרות.
- בסקשן המדריכים, סדר בלוקי `מאמר מוביל` קובע אילו מאמרים מהבלוג המוגדר מופיעים ראשונים. בחירת קולקציה מספקת את הנושא והתמונה כאשר למאמר אין תמונה משלו. מאמרים אחרים ממשיכים להופיע אחריהם.
- כתובת סניף הדגל בתחתית וכתובת בכרטיס הקשר הן הגדרות מקומיות לסקשן. הן אינן משנות את זהות החנות הארצית או את מסלול המשלוח. נתוני סניף הדגל במטא־אובייקט ממשיכים לקבל עדיפות בתחתית.
- קיצור הדרך למעבדת JOY FIX מוביל לכרטיסי הסניפים בצור קשר כל עוד עמוד המעבדה אינו מפורסם. כשהעמוד מפורסם, הקיצור חוזר אליו אוטומטית.

עמודי אודות ומדיניות, תפריטים, תיאורי מוצרים ומטא־אובייקטים נשמרים ב־Shopify בנפרד מהתבנית. [כלי עדכון התוכן וההוראות](.github/storefront-remediation/README.md) כוללים את התיקונים המוכנים ואת בדיקות המצב לפני הפעלה.

## התאמת אביזרים משלימים

דף המוצר והעגלה קוראים את אותה קבוצת התאמות. במוצרים שנבדקו, השדה `custom.joy_addon_groups` מסוג JSON מכיל `version: 1` ו־`groups`, ובכל קבוצה `label`, `word` ו־`tag`. התגית חייבת להתחיל ב־`joy-fit-v1-` ולהופיע גם על האביזר המתאים. כך שם דגם בעברית אינו תלוי בתוצאות חיפוש באנגלית, ודגמי Pro, Pro Max, Plus ו־Ultra מקבלים התאמות נפרדות.

הוספת תגית מצהירה על תאימות: יש לוודא את הדגם המדויק ואת החיבורים של כל הגרסאות במוצר, במיוחד בערכות עם כבל. מוצרים ללא שדה התאמות משתמשים בכללים הקיימים בעורך התבנית. אביזר שאינו זמין אינו מוצג, וכרטיס ההמלצה משתמש בתמונה ובשם של הווריאנט הזמין שנבחר. שדה עם `version: 1` ו־`groups: []` משבית את ההמלצות למוצר באופן מפורש.

במוצרים עם שיוך מאומת, `custom.joy_addon_products` מסוג `list.product_reference` מכיל את האביזרים המקושרים באותה חנות. דף המוצר והעגלה מציגים מתוכם את המוצרים הזמינים והמפורסמים עם תגית הקבוצה המדויקת, ישירות ב־Liquid. כך זמינות ההמלצות אינה תלויה באינדקס החיפוש או בקריאת רשת נוספת. תגיות ההתאמה עדיין מגדירות את החלוקה לקבוצות; המלצות ישנות ללא רשימת הפניות ממשיכות לפעול דרך החיפוש הקיים.

## מוצרים שאזלו

הגדרות ה-theme ← מוצרים שאזלו (כמו בתבנית של אילת, `YonatanKing12/joymobile`). כשההגדרה "מוצרים שאזלו מוצגים באתר" פועלת (ברירת המחדל), מוצר שאזל נשאר באתר עם המחיר שלו:

- בקטגוריה מוצגים קודם המוצרים שבמלאי, לפי הסדר שהלקוח בחר. אחרי העמוד האחרון שלהם, הכפתור "הצגת המוצרים שאזלו מהמלאי" ממשיך לאותה קטגוריה עם הסינון `filter.v.availability=0`. כשהלקוח לא סינן, הכפתור מוצג רק אם יש בקטגוריה מוצר שאזל לגמרי (מוצר שרק חלק מהווריאציות שלו אזלו כבר מוצג עם המוצרים שבמלאי). בחיפוש, שופיפיי מציגה את המוצרים שאזלו בסוף (`options[unavailable_products]=last`). בתוך כל עמוד, מוצר שאזל תמיד מופיע אחרי המוצרים שבמלאי (`snippets/product-grid`).
- בכרטיס המוצר מופיעים הכפתור "בדיקת זמינות" (שיחת טלפון), שורת המלאי "אזל מהמלאי" עם נקודה אפורה ותמונה שקופה יותר.
- בדף המוצר, במקום הקנייה, מופיעים "בדיקת זמינות בסניף" (שיחת טלפון) ו"עדכנו אותי כשחוזר". הכפתור השני פותח טופס עם מספר נייד ותיבת הסכמה לא מסומנת. הטופס נשלח לדשבורד של Joy Mobile (`/api/public/back-in-stock`), והדשבורד שולח הודעת וואטסאפ אחת כשהמוצר חוזר למלאי. גם הפס התחתון בטלפון מציג את שתי הפעולות. כשמחליפים וריאציה, הכפתורים מתעדכנים.
- מספר הטלפון, הטקסטים, נוסח ההסכמה וכתובת הדאשבורד הם הגדרות, ואפשר לשנות אותם בלי קוד. בטקסטים ללקוח לא משתמשים במקפים.

כשההגדרה כבויה, האתר חוזר להתנהגות הקודמת: מוצר שאזל לא מופיע ברשימות, ובדף המוצר יש כפתור "אזל מהמלאי". הדאשבורד מעביר מוצר שאזל לטיוטה רק כשההגדרה `catalog.keepSoldOutVisible` שלו כבויה, ולכן מכבים את שתיהן יחד.
